# Проверенные данные о Павлодаре

Исследование открытых источников от 29.10.2026 (поиск — GPT по промпту команды, выборочная сверка первоисточников — Claude): климатические нормы, нормы СП РК, правила озеленения Павлодарской области, качество воздуха, зелёный фонд, цены госзакупок, население, микрорайоны.

| Файл | Что внутри |
|---|---|
| `sources.json` | 34 источника: название, адрес, дата публикации (`publishedAt`, null — не найдена), дата обращения (`observedAt`), класс `real` / `estimate` |
| `facts.json` | 33 факта для «Справочников» и ассистента; у каждого — `evidenceIds`. `gap: true` — факт об отсутствии данных |
| `climate.json` | Месячные нормы 1991–2020 (JMA), рекорды Казгидромета, альтернативный ряд СП РК — отдельно, ряды не смешиваются |
| `districts.json` | 7 подтверждённых названий микрорайонов; центров, границ и населения нет |
| `prices.csv` | Цены петунии и тагетеса из одной госзакупки (договор и план); в цену входит посадка |
| `norms.md` | Нормы с номерами пунктов: правила области №52/4 (изм. 2026), СП РК 3.01-101-2013 |
| `SOURCE-NOTES.txt` | Оговорки исследователя: что значат null, классы и почему данные нельзя расширять |

Выборочно сверены с первоисточниками: рекорды −47,0 °C (1907) и +42,0 °C (1973), компенсационная посадка ×10 и 3 года ухода, инвентаризация 200 тыс. деревьев и кустарников и план 1 660 деревьев, цены петунии и тагетеса (план 215,52 и 344,83 ₸, договор 175 и 288 ₸). Расхождений не найдено.

Где используется: страница «Справочники» (раздел «Проверенные данные о Павлодаре»), поиск ассистента (`search_knowledge` на сервере и ответы по правилам), проверка размещения посадок (отступ от здания по СП РК), источники в базе сервера (`npm run seed:tz`).

Чего нет и где запросить — в конце `SOURCE-NOTES.txt` и в отчёте исследования: население и границы микрорайонов, инвентаризация деревьев по участкам, акты приживаемости, единичные цены на саженцы, полив и уход, карта почв и засоления.
