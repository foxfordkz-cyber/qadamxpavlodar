# Green Pavlodar — AI-ассистент для озеленения города

Прототип по ТЗ акимата «AI-ассистент для анализа AI-карты и подбора решений по озеленению» (хакатон 28.10–01.11.2026). Работает на открытых данных OpenStreetMap для центра Павлодара. Слои организатора подключаются через импорт.

Локальная серверная интеграция от 29.10.2026: [инструкция и API](apps/server/MUNICIPAL_HANDOFF.md), [фактические проверки и compliance](apps/server/MUNICIPAL_VERIFICATION.md). Старый V2 workflow сохранён. Муниципальная аналитика теперь выполняется backend с SQLite и настоящими сессиями. Экспертные правила не являются подключением LLM/RAG.

## Запуск

Конфигурация запуска одной командой (нужен исправный Docker Engine):

```bash
docker compose up --build
```

Откройте http://localhost:8080.

На текущем компьютере Compose v5.0.1 и конфигурация проверены, Engine не отвечает: **Docker BLOCKED**. Сборка и запуск контейнеров ещё не подтверждены; Docker не устанавливался.

Проверенный локальный путь без Docker (Node.js 24). Backend, первый PowerShell:

```powershell
cd apps/server
npm ci
npm run build
$env:DB_PATH='./data/municipal-demo.sqlite'
$env:PORT='3110'
npm run seed:v2
npm start
```

Frontend, второй PowerShell из корня репозитория:

```powershell
cd apps/web
npm ci
$env:VITE_DATA_SOURCE='api'
$env:VITE_API_PROXY='http://127.0.0.1:3110'
npm run dev -- --host 127.0.0.1 --port 5180
```

Откройте http://127.0.0.1:5180/?source=api. DEMO логины `specialist`, `admin`, `viewer`; публичный тестовый пароль `DEMO-only-2026!`. Swagger — http://127.0.0.1:3110/api/v1/docs. Данные сохраняются в `apps/server/data`, фотографии — `apps/server/uploads`; оба каталога исключены из Git.

При запуске без `VITE_DATA_SOURCE=api` сохраняется старый тестовый режим. В API-режиме нет автоматического fallback на mock при ошибке сервера. Docker Compose явно выбирает API-режим.

Переключатель «⚙ Режим проверки» относится только к mock. В настоящем режиме права берутся из серверной сессии. Старые React-экраны проектов/назначений/приёмки ещё используют отличающиеся DTO; их полный V2 workflow пока проверен через API, а не через эти экраны. Администрирование пользователей/бригад доступно на `/api/v1/admin`.

## Архитектура

```
apps/web/src/shared/analytics/   расчёты ТЗ без доступа к БД: plan.ts (подбор, смета, приживаемость, уход, эффект),
                                 city.ts (проблемы, приоритеты, дорожная карта), rates.ts (справочник),
                                 zone.ts (почва, назначение), assistant.ts (ассистент по правилам)
apps/web/src/shared/api/         контракт API, HTTP-клиент, тестовый источник (mock/) с маршрутами /api/v1
apps/web/src/features/coordinator/  экраны: карта, зона, проблемы, приоритеты, каталог, проекты, справочники, импорт
fixtures/osm/                    загрузка и обработка OSM: зоны, окружение, насаждения
fixtures/photos/                 фото со свободной лицензией (Wikimedia Commons)
```

Стек: React 19 + TypeScript + Vite, MapLibre GL 6 (OpenFreeMap/OSM), three.js (3D-модели посадок). Расчёты — чистые функции TypeScript: серверная часть переносит их без изменений. Подробности интеграции — [docs/coordinator-integration.md](docs/coordinator-integration.md), сверка с ТЗ — [docs/tz-gap-analysis.md](docs/tz-gap-analysis.md).

## Данные, допущения и ограничения

- **Зоны** — 114 газонов и пустырей из OpenStreetMap (ODbL), снимок 27.10.2026. Это кандидаты, а не подтверждённо свободная земля.
- **Почвы** — *синтетический* слой (ячейки 400 м) до получения карты почв организатора. Помечен на карте и в расчётах.
- **Насаждения** — OSM (парки, скверы, деревья); деревья в OSM нанесены неполно.
- **Растения** — 50 видов; польза и устойчивость — обобщение команды (оценка). «Сажают в Павлодаре» — со ссылкой на источник.
- **Приживаемость** — экспертные правила (п.п. по факторам риска), *не калибрована* на данных Павлодара; ROC-AUC не измерялась: нет размеченных данных.
- **Смета** — демо-расценки команды; администратор заменяет их в «Справочниках».
- **Экоэффект** — коэффициенты с источниками (CO₂ ≈25 кг/год на взрослое дерево, задержание дождя ≈2228 л/год, охлаждение 0,8–1 °C). Для пыли и населения данных нет — показываем «нет данных».
- **Ассистент** — сейчас разбор запросов по правилам поверх серверных модулей, личная история в SQLite. LLM + RAG пока не подключены; владелец интеграции — участник 1 совместно с backend.
- Персональные данные граждан не обрабатываются.

Все результаты оценочные и носят рекомендательный характер; решение принимает специалист акимата.

## Краткая инструкция (1 страница)

1. **Карта** → включите слои справа → нажмите на зону.
2. В карточке зоны: **Растения** (закрепите или исключите виды) → **Смета** (выберите вариант) → **Приживаемость** (примените меры) → **Уход** → **Эффект**.
3. **⤓ Отчёт по зоне** → «Печать / PDF» или «Excel».
4. **Приоритеты** → задайте веса и бюджет → получите очерёдность.
5. **Проблемные зоны** → фильтр по типу и остроте → переход к зоне на карте.
6. **✦ Ассистент** → спросите своими словами, например: «что можно озеленить на 50 млн».
