# Шрифты браузерных проверок

Неизменённые Manrope v23 и Oswald v57, которые запрашивает `apps/web/index.html`.
Получены с Google Fonts 30.10.2026. CSS включает исходные начертания и Unicode ranges,
WOFF2 не преобразовывались. URL, размер и SHA-256 каждого файла — в `manifest.json`.
Лицензии SIL Open Font License 1.1 сохранены рядом с файлами; источники лицензий —
официальный репозиторий `google/fonts`, URL указаны в manifest.

`support/test.ts` обслуживает только два font-домена из этих файлов во всех mock/API
контекстах. Это устраняет зависимость функционального прогона и снимков от CDN:
в исходной среде его CSS иногда блокировал DOMContentLoaded, а шрифты — съёмку.
Запросы приложения, `/api`, Wiki-фотографии и карта не перехватываются этой fixture.
Пароли и пользовательские данные в assets отсутствуют. При изменении семейства или
URL шрифта fixture сообщает ошибку; обновлять её следует после просмотра приложения.
Проверка доступности Google Fonts в реальной сети не входит в этот набор.
