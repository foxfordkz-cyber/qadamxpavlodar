## Ограничения и следующий шаг

Docker **не проверен**: docker version не может открыть `//./pipe/dockerDesktopLinuxEngine`, apps/server/.env отсутствует. Не проверены сборка/запуск Compose и mock/API через :8080. На настроенном стенде: из корня `docker compose up --build`; в tools/e2e `$env:E2E_BASE_URL='http://localhost:8080'`, затем `npm.cmd run e2e` и `npm.cmd run e2e:api`. Пароль берётся из окружения или локального .env без печати.

ZIP/XML не заменяет визуальное открытие в настольном Word. Лингвистическую точность видов проверяет Бекзат. В тестах используются локальные копии тех же Manrope/Oswald с OFL-лицензиями и SHA-256; доступность Google Fonts в сети не проверяется. Фотографии и подложка по-прежнему используют сеть; карта может показывать штатную схему. Презентация на конкретном проекторе и видео — отдельная работа команды.
