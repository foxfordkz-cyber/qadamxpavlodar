## E2E-06: навигация встроенного кабинета на desktop

Воспроизведение mock: 1280×800 → главная → «⚙ Режим проверки» → «Работник» → закрыть панель → виден заголовок «Моя смена», но ни «Профиля», ни «Журнала» нет. `npm run e2e -- tests/worker-navigation.mock.spec.ts` → **1 passed (mobile), 1 failed (desktop)**. API: вход worker1 → та же отсутствующая кнопка «Профиль»; пароль в окружении, API-снимки и трассы отключены.

Причина по исходникам `787dd02`: `WorkerCabinet.tsx` передаёт `embedded: true`; `journal.css:26` скрывает `.topbar` у `:host([embedded])`, а `.mobile-nav` видна только при `max-width:800px`. Тест ждёт загрузки CSS, чтобы не нажимать кратковременно видимые неоформленные дубликаты. Принудительные клики не используются.

Ожидалось: на desktop можно перейти в профиль/журнал и завершить сессию из профиля. Получилось: доступны задания и общая кнопка «Выйти» в шапке, а внутренняя навигация недоступна. Влияние на демонстрацию: нельзя показать профиль и историю кабинета на проекторе. Временный обход для показа — телефонная ширина; это не исправление. [Безопасный скриншот mock](evidence/E2E-06-desktop.png), без паролей и реальных рабочих данных. Снять статус ошибки только после исправления приложения и успешного повторения обоих размеров и API.

## Ошибки тестов, исправленные в этой работе

- Старый Word-тест ожидал download сразу после открытия настроек. Сценарий обновлён под отдельную кнопку скачивания #14; до merge успешным не считается.
- Каталог импортирует JSON в синтаксисе Vite. Нативный ESM Node требовал import attribute; тест читает исходный каталог через загрузчик CommonJS Playwright. Код приложения не изменялся.
- В API использовалась неточная подпись «Карта» вместо «Карта участков»; селектор исправлен и проверки admin/viewer повторно прошли.
- Первоначальный селектор профиля выбирал два ещё не оформленных CSS пункта. После ожидания stylesheet выявлен настоящий E2E-06: видимых пунктов на desktop ноль. Исправление селектора не устранило дефект приложения.

## Ограничения окружения

Docker CLI установлен, но Engine недоступен; `apps/server/.env` и внешний `E2E_PASSWORD` отсутствуют. API выполняется на временной seeded SQLite с одноразовым паролем только в окружении дочерних процессов. Это не Docker и не рабочая база. Команды повторения Docker — в RUN-RESULTS.md. ZIP/XML проверка Word не подтверждает настольную вёрстку; настольный Word в этом прогоне не использовался.
