## Исправленные ошибки тестов и ограничение сети

- «Импорт» одинаков в ru.ts и kk.ts: исключён из запрета русских служебных подписей. OSM-имена, адреса, источники и разрешённый nameRu fallback не запрещаются.
- «Смета» показывает статьи расходов, а не названия растений: проверяются перевод заголовков и неизменность всех числовых ячеек; названия видов отдельно проверяются в каталоге, растениях, приживаемости, отчёте и Word.
- Добавлены ожидания данных каталога и CSS после каждого переключения кабинета. Кратковременные неоформленные дубликаты меню больше не вызывают ошибку селектора. Требование видимой навигации не ослаблено.
- Mock при reload заново создаёт демонстрационного специалиста. В нём проверяется немедленная очистка после выхода; сохранение выхода после reload проверяется реальным API.
- Первый полный прогон на 495a9f2: 152 passed / 6 failed / 2 skipped / 0 fixme. Помимо E2E-06 снимок «Приоритетов» упёрся в 45 с: трасса показала загрузку Google Fonts 32–51 с. Только для снимков лимит увеличен до 90 с; ожидание document.fonts.ready сохранено. Итоговый полный прогон и отдельные 26 снимков выполнены заново. Исходная трасса — локально test-results/history/font-timeout/.
- Визуальный просмотр отклонил первые кадры каталога с ещё пустыми фотографиями. Диагностика показала: внешние Wikimedia-фото полностью загружаются примерно за 40 с, ошибок ответов нет. Добавлено ожидание complete/naturalWidth для изображений внутри кадра (до 60 с), без ожидания невидимых картинок и без подмены ресурсов. После этого набор переснят и проверен снова.
- Ранний выборочный Word-прогон однажды не дождался download; причина не установлена. Последующие повторения и полные прогоны RU/KK прошли без retries. Это наблюдение сохранено, но не объявлено подтверждённым дефектом приложения.
- После восстановления соединения запуск на 27d9067 дал 150 passed / 8 failed / 2 skipped / 0 fixme: пять E2E-06 и три сбоя загрузки (открытие /species на 1280 px, открытие /priorities у администратора на 375 px, ожидание fonts.ready для снимка /projects на 375 px). API дал 5 passed / 2 failed: E2E-06 и timeout формы входа viewer. В mock-трассе локальные модули ответили 200, CSS fonts.googleapis.com остался незавершённым; причина API-таймаута без trace не доказана. Исходные результаты сохранены в test-results/history/navigation-timeout. Для QA добавлены неизменённые Manrope v23 / Oswald v57 с OFL-лицензиями, URL и SHA-256: support/test.ts обслуживает только два font-домена из fixtures/fonts. API, фотографии и карта не подменяются.
