## Переключатель в шапке

После слияния PR #9 (`787dd02`) переключатель подключён в `Shell.tsx` рядом с «Выйти», в том числе для экрана входа. Логика авторизации, выхода и маршрута `#/worker` сохранена. Импорт:

```tsx
import { LanguageSwitcher } from '../../shared/i18n/LanguageSwitcher';
```

Элемент в `gp-header__right` — одна строка:

```tsx
<LanguageSwitcher />
```

Язык можно выбрать кнопками «Рус / Қаз» или адресами `/?source=mock&lang=kk` и `/?source=api&lang=kk` (маршрут страницы остаётся после `#`). Язык сохраняется в `localStorage` под ключом `gp.language`. Смена языка вызывает повторный рендер без размонтирования страницы и потери введённой формы. URL `lang` имеет приоритет при загрузке. `VITE_ENABLE_KK=0` явно отключает казахский; без флага он доступен. Переключатель меняет общий интерфейс; внутренние тексты кабинета работника ведутся в отдельном модуле.

`t(key)` использует русский текст, если перевода нет. `tr(text)` — адаптер старых статических подписей: ищет строку в ru и берёт парный ключ kk, неизвестную строку сохраняет как есть. Переводы и для этого адаптера находятся в `kk.ts`; автоматического машинного перевода ответов API нет.

## Граница перевода и интеграционные хвосты

- Переведены исходные 691 ключ и добавлены пары для статических подписей разрешённых страниц, включая отчёт, каталог, смету, приоритеты, импорт и гайд. Месяцы и подписи общих аналитических словарей переводятся во время рендера, а не при загрузке модуля.
- После слияния `origin/codex/coordinator` (`3795f16`) переведены новые элементы `SitesPage`, `TimeMachinePanel`, `AssistantPanel`, режим презентации и действия пустых списков. Вкладки `ZONE_TABS` в карточке выводятся через `tr(label)`. Названия подсветки хранятся в URL как ключи (`hlt`, бюджет — `hlb`), переводятся при рендере; старые ссылки с русским заголовком поддерживаются.
- В `map/MapTools.tsx` по отдельному разрешению переведены только тексты поиска и рисования (`mapSearch.*`, `draw.*`), включая скрытые подписи. Обработчики, условия, расчёт площади и сохранение не менялись. Остальные `map/*` не редактировались; в `Shell.tsx` после PR #9 добавлены только импорт и элемент переключателя.
- Счётчики над списком зон и плитки обзора переводят `label` и `definition` через `tr()` при отображении. `metricPeriod()` переводит известную подпись периода OSM, сохраняя дату; неизвестный текст возвращается как есть. `dashboardMetrics` и другие исходные данные остаются на русском.
- После слияния `origin/codex/coordinator` (`dc6d56d`, включает PR #13) сохранены импорт SHP с предварительной проверкой и подтверждением, серверный экспорт PDF/XLSX и Word-записка. Новые подписи и сообщения интерфейса — `import.*` / `report.*`; значения слоёв и классов данных в запросах не переводятся. Сообщения API и пользовательские данные сохраняют исходный текст.
- `shared/analytics/assistant.ts`, `apps/server/src/tz/llm.ts`, `tz/assistantCommands.ts`, `apps/server/src/v2/*` и `apps/server/src/municipal/*` не редактировались при интеграции. В `AssistantPanel` переведены подписи, примеры вопросов и два локальных сообщения команды рисования (`assistant.drawEnabled`, `assistant.drawRestricted`); текст ответа, названия объектов, источники и причины fallback из API отображаются как получены.
- Имена объектов, пользовательский текст, названия/цитаты источников, описания видов и объяснения, пришедшие от API/расчёта, сохраняют язык исходных данных. Их отдельного казахского набора в текущем контракте нет; русская строка не маскируется пустым переводом. Названия видов не переводились без подтверждённого ботанического соответствия.
- Служебная записка создаётся на выбранном при скачивании языке «Рус / Қаз», независимо от языка интерфейса. Служебные тексты — ключи `memo.doc.*`, подписи и шаблоны расчёта — `memo.input.*` в общих `ru.ts` / `kk.ts`. `tFor` и `trFor` принимают язык явно, не меняя глобальное состояние. Числа, формулы и исходные результаты расчёта сохраняются; для Word задан язык проверки `ru-RU` / `kk-KZ`.
- Названия объектов, цитаты/описания источников и неизвестные пользовательские тексты сохраняют язык оригинала. Для вида используется `nameKk`, если он есть, иначе `nameRu`; новые ботанические переводы не выдумываются. Известные шаблоны объяснений из расчёта переводятся только при полном совпадении, параметры переносятся без пересчёта. Содержимое документа полностью редактируется в Word.

## Проверка

```bash
npm --prefix apps/web run check:i18n
npm --prefix apps/web run test
```

`check:i18n` завершается с ошибкой при пропущенном/пустом переводе, лишнем ключе или несовпадении имён и количества `{параметров}`. Русский fallback проверяется отдельным тестом. Полнота словаря не равна лингвистической вычитке или проверке каждой страницы в браузере.
