## Интеграция переключателя после PR #9

`Shell.tsx` в этой ветке не меняется. Импорт в шапке:

```tsx
import { LanguageSwitcher } from '../../shared/i18n/LanguageSwitcher';
```

Вставка в `gp-header__right` — одна строка:

```tsx
<LanguageSwitcher />
```

До интеграции шапки проверяйте `/?source=mock&lang=kk` и `/?source=api&lang=kk` (маршрут страницы остаётся после `#`). Язык сохраняется в `localStorage` под ключом `gp.language`. Смена языка вызывает повторный рендер без размонтирования страницы и потери введённой формы. URL `lang` имеет приоритет при загрузке. `VITE_ENABLE_KK=0` явно отключает казахский; без флага он доступен.

`t(key)` использует русский текст, если перевода нет. `tr(text)` — адаптер старых статических подписей: ищет строку в ru и берёт парный ключ kk, неизвестную строку сохраняет как есть. Переводы и для этого адаптера находятся в `kk.ts`; автоматического машинного перевода ответов API нет.

## Граница перевода и интеграционные хвосты

- Переведены исходные 691 ключ и добавлены пары для статических подписей разрешённых страниц, включая отчёт, каталог, смету, приоритеты, импорт и гайд. Месяцы и подписи общих аналитических словарей переводятся во время рендера, а не при загрузке модуля.
- Файлы `map/*`, `sites/*`, `tz/AssistantPanel.tsx`, `Shell.tsx` не менялись. Их существующие вызовы `t` получают перевод; оставшиеся литералы в них должен подключить владелец этих файлов. Например, вкладки `ZONE_TABS` в защищённой странице нужно выводить через `tr(label)`.
- Имена объектов, пользовательский текст, названия/цитаты источников, описания видов и объяснения, пришедшие от API/расчёта, сохраняют язык исходных данных. Их отдельного казахского набора в текущем контракте нет; русская строка не маскируется пустым переводом. Названия видов не переводились без подтверждённого ботанического соответствия.
- Служебная записка создаётся на русском; кнопки и пояснение экспорта переведены. Содержимое документа полностью редактируется в Word.

## Проверка

```bash
npm --prefix apps/web run check:i18n
npm --prefix apps/web run test
```

`check:i18n` завершается с ошибкой при пропущенном/пустом переводе, лишнем ключе или несовпадении имён и количества `{параметров}`. Русский fallback проверяется отдельным тестом. Полнота словаря не равна лингвистической вычитке или проверке каждой страницы в браузере.
