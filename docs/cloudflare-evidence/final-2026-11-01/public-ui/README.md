| API, прямой `?source=api&lang=kk#/worker` | Казахский экран входа и источник `/api/v1`, без подмены учебным кабинетом; Рус/Қаз переключаются; KK после reload сохраняется |

| Публичная записка для существующего участка Толстого | RU/KK DOCX реально скачаны через UI с immutable mock, затем открыты в Microsoft Word 2016 в Protected View без запроса восстановления файла |

Mock после полного reload возвращает учебную роль координатора: выбранный язык сохраняется, worker/foreman нужно выбрать снова. Это существующее поведение mock, не результат проверки серверной сессии. На 375 px бейдж источника данных частично обрезан; навигация и действия доступны. Замечание было также зафиксировано локально до публикации.

Публичный smoke **не проверял** внутренний ключ идемпотентности, повтор после неоднозначной сетевой ошибки, полноценный отказ backend, реальную загрузку приватного фото или облачную приёмку. Эти результаты нельзя заменять локальными тестами или прежним циклом Бекзата. Согласованного приватного DEMO-доступа нет; новый cloud login/logout и роли остаются **NOT RUN**.
