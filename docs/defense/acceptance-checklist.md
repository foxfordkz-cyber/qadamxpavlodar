## Облачная приёмка

Все пункты ниже PENDING до фактического результата с URL, web/server SHA, временем, режимом и свидетельством. Публикация mock и тесты Node не закрывают их.

- Получен контракт Бекзата: API URL/SHA, постоянные БД и фото, cookie/CSRF, proxy/readiness и эксплуатационные ограничения.
- На публичном API-адресе вход и выход всех нужных ролей, ограничения чтения/записи; браузер использует проверенный маршрут API, нет обращений к localhost/частным адресам команды.
- Общая операция на одной БД: задание → worker фото/отчёт → coordinator review → повторное чтение. Бригадир не получает права окончательной приёмки.
- Фото и принятые данные доступны после reload, повторного входа, проверки с другого разрешённого контекста и перезапуска backend; одно лишь сохранение в браузере не доказательство.
- Проверены multipart/binary, приватные фото, cookie/CSRF и отсутствие API-кэша в реальном Cloudflare runtime.
- Холодный старт и 502/503/504/сетевая ошибка: понятное ожидание, ограниченное число read-only проверок, отмена и явный повтор; нет бесконечного spinner и скрытой замены API на mock.
- Потеря ответа после сохранения фото/отчёта: черновик/ключ остаются, ручной повтор не создаёт дубль; автоматических отправок при reconnect нет.
- **Физический телефон через мобильный интернет, локальный backend и туннель выключены.** Проверены открытие, вход, фото, состояние данных и отсутствие зависимости от компьютера команды. Камера/системная клавиатура отмечаются по факту.
- Айдана проверила UI/числа/ограничения на принятых SHA; Бекзат подтвердил адрес и данные; Дамир согласовал общий результат.

Для публичного M отдельно проверить RU/KK, desktop/mobile, маршруты, записки, кабинет и независимость от локального backend/туннеля на физическом телефоне. Серверное хранение в mock не заявлять даже после этой проверки.
