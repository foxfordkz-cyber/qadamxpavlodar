**Оригинал раздела 8 ТЗ отсутствует в доступных исходниках.** В `origin/docs/team-plan` (`968c2414acf6a394d266165a8f9634c8dcbe50b6`) найдены только ссылки на него и пересказ команды. D01–D18 ниже — внутренние проверки по известным требованиям, а не официальные номера критериев. Полноту раздела 8 пока подтвердить нельзя. Не ставить общую приёмку по этой таблице до сверки с первоисточником.

## Правила статуса

- **проверено** — указан воспроизводимый прогон, конкретная сборка/режим, фактический результат и свидетельство; чтение кода не подтверждает пользовательский сценарий.
- **ожидает проверки** — проверка не выполнена или имеется только историческое/косвенное свидетельство; это не «успех» и не доказанный дефект.
- **блокировано** — известное препятствие не даёт завершить конкретную проверку; указана причина и условие снятия блока.

Последний учтённый снимок `coordination/qa.md`: **FINAL QA COMPLETE, 29.10.2026 15:15 UTC+5**; отдельно прочитаны API-отчёты. Сервер — `origin/server/srv-03-06` (`1fa8e2f`); веб — `18c2541` с локальными изменениями. **Прямые API-цепочки обследования и посадки прошли; полный браузерный сценарий через API блокирован.** Назначение, начало, фото, отчёт и его исправление через UI проверены в **HYBRID**: создание задания, возврат и приёмка выполнены API. Финальный UI показывает принятую правку. Все 5 ролей вошли и отобразились; это не полная приёмка прав. Смена даты, logout и роль прошли финальные retest; прежний `null.type` не является активным блоком. Viewer read-scope не соответствует ожиданию. Старые PASS изолированного демо не переносятся в текущую браузерную приёмку.

Отдельно от этих проверок завершён и записан standalone mock UI-цикл `GP-PLANT`: итог 2 дерева + 4 кустарника, возврат/исправление/приёмка через тестовую панель; 2 загрузки, 2 вклада, 2 отчёта, 6 учебных растений. Это третий независимый scope, не доказательство единого main coordinator→worker сценария.

В основной таблице **mock** относится к основному приложению, а **api — браузер** — к его экранам с `?source=api`. Ни standalone-стенд, ни прямые HTTP-запросы не дают автоматического PASS этим столбцам.
