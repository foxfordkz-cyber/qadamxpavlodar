Затем в карточке явно выбираем **три года**: «Сквер», «Оптимальный», все ярусы, регулярный полив, без улучшения почвы, доля вида 30%. Контрольная смета — **10 825 628 ₸**, уход — **2 565 450 ₸**. Отчёт открывается ссылкой из карточки, которая передаёт эти параметры; Word использует их же. Две суммы не выдаются за один расчёт с неизменными входами.

Лаборатория: бюджет **50 млн ₸**, общий лимит **1 000 → 500 м³ за сезон**, «Сбалансированный план», «Обычный» полив. Кабинет показан перед лабораторией. Outcomes отдельно сравнивает **только деревья с тремя годами ухода**; его суммы не равны смешанной смете участка.

## Ограничения, которые видит зритель

Модель первого года обучена на синтетике и не калибрована на посадках Павлодара. Второй и третий годы используют экспертное затухание. Демо-посадки и осмотры вымышлены. Отклонение одной партии не доказывает точность модели; неизвестное состояние не означает гибель. Формы новой партии и нового осмотра в текущем Outcomes UI отсутствуют.

Кабинет — адаптивный веб-интерфейс. При «Қаз» оболочка kk, встроенный кабинет ru; standalone `kk-draft` переводит лишь часть строк. Основной mock и worker demo имеют отдельные учебные хранилища. Физический телефон не проверялся.

Полный исторический API E2E на c08efea имеет четыре падения на устаревшем KK-локаторе лаборатории. Они не замалчиваются и не переписываются в PASS. На a66d542: typecheck/build и четыре check:* PASS, worker 79/79, полный web-повтор 192/192, целевые mock-тесты 22/22, responsive 20/20, повтор API E2E-06 16/16. Первый web-запуск имел 177 PASS и сбой процесса decisionLab без установленной причины; отдельный повтор 15/15 и полный повтор сохранены. Первая API-попытка дала 15 PASS / 1 FAIL с неизвестной причиной, её журнал также сохранён. Точный scope и среды перечислены в чек-листе.

Комплект **`green-pavlodar-show-fdc6e75.zip`** объединяет portable runtime **fdc6e75**, неизменённые медиа **a66d542** и свежие Word/QR в `final-fdc6e75`. Запуск — корневой **`start-mock.cmd`**, встроенный Node и loopback `127.0.0.1:5194`; API он не подменяет. Холодная offline-проверка runtime: **17/17 PASS**, **39/39 файлов manifest**, а 34 файла приложения совпадают с опубликованным mock по SHA256. Внешние тайлы/фотографии без сети не обещаются: использовать «Схема», локальные PDF и ролики. ## Запасной показ

1. До выступления открыть локальные PDF и оба MP4, проверить читаемость и звук/субтитры.
2. В текущем пакете `green-pavlodar-show-fdc6e75.zip` запустить корневой `start-mock.cmd`; runtime fdc6e75, встроенный Node, порт 5194. Старый offline a66d542 остаётся отдельным резервом.
3. При сбое API явно перейти на mock. Если недоступна подложка карты или внешние изображения, перейти на MP4/PDF той же версии.
4. Для карты без сети выбрать «Схема». Холодный запуск ограниченного mock-показа проверен в чистых контекстах: 17/17, вся внешняя сеть заблокирована. Внешние тайлы, фотографии и сетевой поиск недоступны; это не полная автономная карта. Видеофайлы и PDF не зависят от API.

Внешние проверки — регламент, независимый просмотр именно медиа защиты, командная устная репетиция, полный постраничный просмотр Microsoft Word и физический телефон — остаются отдельными.
