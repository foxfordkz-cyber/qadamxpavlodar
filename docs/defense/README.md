Отклонение одной партии не доказывает точность модели; неизвестное состояние не означает гибель. Формы новой партии и нового осмотра в текущем Outcomes UI отсутствуют.

Кабинет — адаптивный веб-интерфейс. При «Қаз» оболочка kk, встроенный кабинет ru; standalone `kk-draft` переводит лишь часть строк. Основной mock и worker demo имеют отдельные учебные хранилища. Физический телефон не проверялся.

Полный исторический API E2E на c08efea имеет четыре падения на устаревшем KK-локаторе лаборатории. Они не замалчиваются и не переписываются в PASS. 1. До выступления открыть локальные PDF и оба MP4, проверить читаемость и звук/субтитры.
2. Запустить `offline/start-mock.cmd` и открыть локальный адрес из инструкции. Node.js включён в готовый Windows-пакет, отдельно устанавливать его не нужно; локальный порт 5194 должен быть свободен.
