# Локальный mock-резерв Green Pavlodar

Версия приложения: `a66d542c63c527d608400c84b34d49f982855369`. Это демонстрационные данные, не подключение к рабочему API.

## Запуск готового Windows-пакета

1. Полностью распакуйте папку `offline` на локальный диск.
2. Запустите `start-mock.cmd`. Установка Node и npm не нужна: runtime находится внутри пакета.
3. Браузер откроет `http://127.0.0.1:5194/?source=mock&lang=ru#/`.
4. Держите окно сервера открытым; остановка — **Ctrl+C**. Если порт занят, закройте прежний локальный сервер и повторите запуск.

Сервер слушает только `127.0.0.1:5194`. Он раздаёт только статические файлы; `/api` отвечает ошибкой 503, а не демонстрационным успехом. Настоящие операции API в этом пакете недоступны. Сохранения в mock остаются учебными, в локальном хранилище браузера.

## Показ без сети

Используйте вкладку **«Схема»** на карте: она показывает геометрию из локальных данных и содержит предупреждение, что это не подробная карта. Внешние тайлы, фотографии и сетевой поиск без интернета недоступны. Пакет не является полной офлайн-картой. Для вида городской подложки и 3D используйте заранее записанный локальный ролик; PDF со слайдами находится рядом с папкой `offline`.

Маршрут резерва: обзор → Толстого → схема → смета с уходом 3 года (**10 825 628 ₸**) → лаборатория (**50 млн ₸**, вода **1000 → 500 м³**, затем отдельное перестроение) → прогноз и факт → кабинет работника («Смена / Журнал / Профиль»). Внутри кабинета перевод KK неполон.

Фактическая браузерная проверка и ограничения перечислены в `verification.json`. Она выполняется в новом контексте с блокировкой всех сетевых адресов, кроме самого `127.0.0.1:5194`; кэш предыдущего показа не используется.

## Воспроизведение пакета разработчиком

Из PowerShell 7 вызовите `build-offline.ps1` с путями `-SourceDist <apps/web/dist> -NodeExecutable <node.exe> -OutputDirectory <новая пустая папка>`. Требуется уже собранный dist закреплённой версии и Node v24.22.1. Скрипт копирует dist и runtime, загружает полный официальный файл LICENSE для тега v24.22.1, записывает SHA-256 каждого файла в `package-manifest.json`. Эта сборка требует сети только для получения лицензии; запуск готового пакета — нет.

Источник лицензии Node: [nodejs/node v24.22.1 LICENSE](https://github.com/nodejs/node/blob/v24.22.1/LICENSE). Полный текст с уведомлениями сторонних компонентов сохранён в `runtime/LICENSE.node.txt` готового пакета. Бинарный runtime и dist не хранятся в Git; в репозитории находятся только инструкции и воспроизводимые скрипты.
