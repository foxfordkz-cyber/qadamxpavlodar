## Проверка

Финализатор: package integrity, layout и импорт PPTX проходят; 9 слайдов. Каждый слайд и каждая из 9 страниц PDF просмотрены отдельно. Таблица сметы проверена арифметически. Нативное выполнение в PowerPoint в этой проверке не заявляется. PDF — визуальная копия проверенных слайдов; редактируемый оригинал — PPTX.

Честные ограничения включены в слайды и заметки: синтетическое обучение, вымышленная история осмотров, неизвестные не равны погибшим, история не является формой нового осмотра, кабинет — адаптивный веб, внутренний перевод KK неполон. Публичный адрес не добавлен.

Видео смонтировано из реальных браузерных действий, ожидания между сценами, перезагрузка и пересчёт сокращены. Русская синтезированная озвучка обозначена в каждом кадре. Все три раздела кабинета видны на компьютере и в viewport 375 px; возврат мобильной вставки со страницы профиля на смену в монтаж не вошёл. Это не проверка физического телефона и не непрерывный дубль.

В полном локальном архиве есть START-HERE.html, видео, документы и готовый offline-пакет Windows x64 с переносимым Node.
