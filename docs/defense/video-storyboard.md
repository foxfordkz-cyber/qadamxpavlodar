## Запасной показ без сети

В полном локальном архиве открыть `START-HERE.html`: доступны MP4, PDF, PPTX и обе записки. Для интерактивного режима Windows x64 запустить `offline/start-mock.cmd`; включён переносимый Node, установка и npm не нужны. Адрес **http://127.0.0.1:5194/?source=mock&lang=ru#/**. Закрытие окна сервера останавливает стенд. [Инструкция и исходники](media/final-a66d542/offline/README.md).

Холодный запуск проверен в чистом браузере с блокировкой всех внешних запросов. Карточки, смета, лаборатория, Outcomes и кабинет работают локально. Внешние тайлы недоступны: использовать «Схема», а для вида карты — слайды и видео. Локальный сервер возвращает для `/api` 503, не подменяет API ложным успехом. Mock не подтверждает production API.
