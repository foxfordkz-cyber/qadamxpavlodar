## Единые входы

Участок `site-osm-1569993037`. Начальный главный «Обзор» использует **два года ухода и около 9,97 млн ₸**; титр и озвучка объясняют переход к трём годам. Основная карточка: «Сквер», «Оптимальный», все ярусы, регулярный полив, без улучшения почвы, доля вида 30%, без ручных замен, уход **3 года**. Отчёт сохраняет параметры: `#/report?site=site-osm-1569993037&o=eyJjYXJlWWVhcnMiOjN9`. Без параметров он возвращает настройки по умолчанию и другую смету.

Лаборатория — многозонный расчёт: balanced, обычный полив, 50 млн ₸, 1 000 → 500 м³. Outcomes — отдельная стоимость деревьев за три года; с годовым наблюдением сравнивается прогноз за один год. Горизонты и сметы не смешиваются.

## Запасной показ без сети

В полном локальном архиве открыть `START-HERE.html`: доступны MP4, PDF, PPTX и обе записки. Для интерактивного режима Windows x64 запустить `offline/start-mock.cmd`; включён переносимый Node, установка и npm не нужны. Адрес **http://127.0.0.1:5194/?source=mock&lang=ru#/**. Закрытие окна сервера останавливает стенд. [Инструкция и исходники](media/final-a66d542/offline/README.md).

Холодный запуск проверен в чистом браузере с блокировкой всех внешних запросов. Карточки, смета, лаборатория, Outcomes и кабинет работают локально. Внешние тайлы недоступны: использовать «Схема», а для вида карты — слайды и видео. Локальный сервер возвращает для `/api` 503, не подменяет API ложным успехом. Mock не подтверждает production API.

## Контроль перед выступлением

Открыть короткий ролик со звуком, PDF и Word на компьютере выступления; сверить a66d542. После изменения продуктового SHA проверить числа и перезаписать затронутые сцены. Word отрендерен через LibreOffice; открытие в Microsoft Word человеком, реальные телефоны, командная репетиция и согласование кадров Айданой отдельно не подтверждены. Публичный адрес не включён без подтверждения Бекзата.
