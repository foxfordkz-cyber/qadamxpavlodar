## Не выполнено / не принято

- Полная перекрёстная матрица каждого экрана RU/KK × 375/1280 и пять настоящих API-ролей.
- Настоящее облачное фото → отчёт → проверка → viewer; постоянство БД/фото; восстановление реального Render. Нет передачи Бекзата (`docs/cloud-api-contract.md`, URL, проверенный SHA).
- Сетевой trace браузера всех запросов: совпадение файлов и статический аудит не заменяют этот тест. Стандартные внешние карты используют HTTPS; тестовые URL в коде отдельно разобраны в локальном HTTP-отчёте.
- Физический телефон через мобильный интернет при остановленных локальных backend и туннеле. Запрос владельцу отправлен; подтверждения пока нет.
- Визуальный просмотр обеих записок в Microsoft Word. Word запущен, но Windows отклонила автоматический ввод; владелец должен открыть файлы. ZIP/XML и скачивание не считаются заменой.
- Новые итоговые слайды и ролик. Обновлены сценарий и видеоплан; финальная запись должна соответствовать принятому источнику и SHA.
