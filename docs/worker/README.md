# Кабинеты работника и бригадира · V2

Подготовка участника 4, ветка `codex/worker-and-demo`. Основа — `codex/coordinator` (8456529).
Модуль добавлен отдельно от экранов координатора. Корневой README, зависимости и маршруты общей сборки сохранены.

## Запуск демо

Из корня репозитория (Node.js 20+, без установки дополнительных зависимостей):

```sh
npm --prefix tools/worker-demo run dev
```

Открыть http://127.0.0.1:4173. В Windows также можно запустить `tools/worker-demo/START-WORKER.cmd`.
Остановка — Ctrl+C. Проверки: `npm --prefix tools/worker-demo test`.

## Возможности

- Смена и карточка задания, начало после ответа источника, фото, заметка, сообщение о проблеме.
- Назначение исполнителей бригадиром с проверкой состава, навыков, времени и ресурсов на тестовом источнике.
- Материалы работников в общем черновике, итог бригадира, возврат координатором и исправление.
- Плановые и фактические количества, исполнители, согласованная версия проекта и синтетическая схема.
- Локальные черновики IndexedDB, повтор с тем же ключом, явное разрешение конфликта версии.
- Разбор заметки с подтверждением человеком; в демо — правила, без настоящей модели.

## Границы готовности

В текущем основном приложении нет маршрута на этот модуль: он запускается отдельно как стенд и подготовлен для встраивания.
Тестовый источник не заменяет сервер. Неполностью определённые тела запросов нужно сверить с реальным backend V2; его ветка не объединяется этим коммитом.
Данные — синтетические: две бригады, восемь задач, две позиции каталога, смена 28.10.2026 UTC+5.
Модуль бригад дополняет основной сценарий анализа участка, подбора, сметы, ухода и эффекта из общего README.

28 автоматических проверок относятся к локальной логике. 28.10.2026 прошла сборка общего frontend: `npm --prefix apps/web run build` (TypeScript проверил React-обёртку; Vite собрал текущие маршруты команды). Модуль ещё не подключён к этим маршрутам. Журнал: `tools/worker-demo/qa/team-build.txt`; сборка предупреждает о крупных JS-чанках.
Финальная визуальная проверка V2 и полный цикл на телефоне не завершены из-за сохранённого запрета инструмента на доступ к localhost.
Свежие скриншоты и резервное видео отсутствуют. Черновик казахского перевода не проверен носителем.
Тексты защиты относятся к модулю работ; перед выступлением нужно согласовать их с общим продуктом и официальным регламентом.
