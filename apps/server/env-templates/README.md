# Шаблоны модели ассистента

Готовые блоки для `apps/server/.env`: адреса, модели и хосты уже заполнены, вставить нужно только ключи.
Модели проверены 29.10.2026 на бесплатных ключах: все вызывают функции расчёта.

| Файл | Основная | Резерв | Время ответа ассистента |
|---|---|---|---|
| `groq-gemini.env` — **рекомендуется** | Groq `openai/gpt-oss-120b` | Gemini `gemini-3.5-flash-lite` | ≈1,5 с; при лимите Groq — 4–9 с |
| `groq-gemini-ollama.env` | Groq | Gemini, затем локальная Ollama `qwen3:8b` | без интернета отвечает Ollama |
| `deepseek-groq.env` | DeepSeek `deepseek-flash` (платно) | Groq | не замерялось |
| `grok-groq.env` | Grok `grok-4.20-0309-non-reasoning` (платно) | Groq | не замерялось |

Бесплатный Groq выдерживает 2–3 вопроса в минуту, потом на время отвечает резерв — сервер переключается сам и пишет под ответом, что ответила резервная модель.

Как подключить:

1. Откройте нужный файл и вставьте ключи после `=` в строках `LLM_API_KEY`, `LLM2_API_KEY`.
2. В `apps/server/.env` замените всё от строки `# === Модель ассистента` до конца этим блоком. Если `.env` ещё нет — скопируйте `apps/server/.env.example` в `apps/server/.env`.
3. Проверьте: `npm --prefix apps/server run llm:check` — покажет для каждой модели, принят ли ключ, есть ли модель у провайдера, вызывает ли она функции и сколько секунд отвечает.
4. Перезапустите сервер. В журнале появятся строки `Assistant model: …` и `Assistant reserve 1: …`.

`ALLOWED_HOSTS` к модели не относится: там адреса, по которым открывают сайт (например, IP ноутбука в сети жюри). Для работы на своём компьютере оставьте пустым.

Ключи храните только в `apps/server/.env`: он не попадает в git.
