# Шаблоны модели ассистента

Готовые блоки для `apps/server/.env`: адреса, модели и хосты уже заполнены, вставить нужно только ключи.

| Файл | Основная модель | Резерв | Стоимость |
|---|---|---|---|
| `gemini-groq.env` | Gemini `gemini-3.8-flash` | Groq `llama-3.3-70b-versatile` | бесплатно, с лимитами — **рекомендуется** |
| `deepseek-groq.env` | DeepSeek `deepseek-flash` | Groq | DeepSeek платно, дёшево |
| `grok-groq.env` | Grok `grok-4.20-0309-non-reasoning` | Groq | Grok платно |
| `ollama-groq.env` | Ollama `qwen3:8b` на своём компьютере | Groq | бесплатно, нужна мощная машина |

Как подключить:

1. Откройте нужный файл и вставьте ключи после `=` в строках `LLM_API_KEY` и `LLM2_API_KEY`.
2. В `apps/server/.env` замените всё от строки `# === Модель ассистента` до конца этим блоком. Если `.env` ещё нет — скопируйте `apps/server/.env.example` в `apps/server/.env` и сделайте то же самое.
3. Проверьте ключи и модели: `npm --prefix apps/server run llm:check`. Команда покажет для каждой модели, принят ли ключ, есть ли такая модель у провайдера, вызывает ли она функции и сколько секунд отвечает.
4. Перезапустите сервер. В журнале появятся строки `Assistant model: …` и `Assistant reserve 1: …`.

Ключи храните только в `apps/server/.env`: он не попадает в git. В шаблоны и в `.env.example` ключи не вписывайте.
